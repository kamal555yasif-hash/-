# IS UNIVERSE

موقع تفاعلي للأدوات التقنية والمسارات المهنية في نظم المعلومات (عربي / إنجليزي).

## الهيكل
- `index.html` الصفحة الرئيسية
- `css/style.css` تصميم الموقع، و`css/intro.css` الثقب الأسود وشاشة الترحيب
- `js/skills.js` المهارات (أضف صفاً جديداً في SK_ROWS)
- `js/data.js` بيانات الأدوات والوظائف (أضف أداة جديدة هنا)
- `js/app.js` منطق الموقع، و`js/intro.js` المقدمة، و`js/ui.js` زر العودة للأعلى

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً وارفع محتويات هذا المجلد.
2. من Settings ثم Pages اختر Deploy from a branch، ثم فرع main والمجلد root.
3. سيعمل الرابط بعد دقائق.
